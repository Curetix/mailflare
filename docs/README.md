# MailFlare Documentation

Create and manage email aliases with Cloudflare Email Routing, from your browser or as a web app.

## Quick Start

1. **Install the extension.** Download MailFlare for
   [Chrome](https://chromewebstore.google.com/detail/mailflare-email-alias-ext/aomfbgcabccoecaoimicmmkjdmdgcfpi)
   or [Firefox](https://github.com/Curetix/mailflare-extension/releases/latest), or use the
   [web app](https://app.mailflare.cc).
2. **Create an API token.** Generate a Cloudflare API token with the right permissions; see
   [API Token Setup](guides/api-token.md).
3. **Manage your aliases.** Create, edit, search, and delete email aliases across all your
   Cloudflare domains.
4. **Use the context menu.** Right-click on any page to generate a new alias for the current site
   and copy it to your clipboard.
